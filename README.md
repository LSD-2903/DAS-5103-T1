# Trabalho Computacional #1 de Cálculo Numérico para Controle e Automação

## Objetivo
Este repositório tem como objetivo armazenar a implementação dos algoritmos numéricos propostos no Trabalho 1 da disciplina de Cálculo Numérico.
Para cada método, é apresentada sua implementação, sua aplicação ao problema proposto pelo professor e a impressão de gráficos para auxiliar na visualização e análise do funcionamento dos métodos e seus resultados obtidos.

## Instalação
Após clonar o repositório, acesse o diretório raiz:
cd DAS-5103-T1
Instale as dependências utilizando o arquivo requirements.txt:

pip install -r requirements.txt

## Execução
Os algoritmos devem ser executados no diretório raiz.

## Exemplo
python -m ex2.gauss
